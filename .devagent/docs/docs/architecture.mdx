# Architecture Diagrams

The LikeC4 model in `.devagent/architecture/` is the source of truth for product architecture. These diagrams document the current scaffold and the intended boundaries for the kamado BBQ coach so future agents can add features without flattening the product into a generic recipe app.

The key separation: the **Vue SPA** owns the user experience, the **Bun API** owns domain and LLM boundaries, and **SQLite** owns durable personal memory. The frontend should not call an LLM provider directly because coaching quality depends on active-session context, cook history, preferences, and prompt hygiene owned by the backend.

Shows the shipped Vue Router boundary: Today, ID-addressed Live, Plan, Coach, Learn, and Logbook render through the responsive `ProductShell`, while `/showcase` remains outside product chrome.
