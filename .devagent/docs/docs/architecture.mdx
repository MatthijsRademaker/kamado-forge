# Architecture Diagrams

The LikeC4 model in `.devagent/architecture/` is the source of truth for product architecture. These diagrams document the current scaffold and the intended boundaries for the kamado BBQ coach so future agents can add features without flattening the product into a generic recipe app.

The key separation: the **Vue SPA** owns the user experience, the **Bun API** owns domain and provider boundaries, and **SQLite** owns durable personal memory. Coach calls stay backend-only because the server resolves authoritative active-session context and controls disclosure. This slice ships explicit fake and disabled modes; no production LLM vendor is selected.
